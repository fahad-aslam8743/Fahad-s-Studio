# Irfan's Studio — Phase 1

TypeScript monorepo foundation for the JARVIS-style Electron desktop app with Next.js UI, Fastify API, Gemini and Supabase pgvector.

This repository is being initialized for the Irfan's Studio application; the repository name is historical and does not determine product branding.

## Intended structure

- apps/desktop — Electron main/preload, Windows installer
- apps/ui — static-export Next.js holographic HUD
- services/api — Fastify, Gemini, voice, tool registry and memory APIs
- packages/shared — common schemas and types

**Status:** Initial repository commit. The locally authored source archive is separate; it has not yet been fully uploaded to this repository. Do not treat this README as a completed build.
