# Fahad's Studio — Known Limitations & Platform Restrictions

This document provides transparent, technical documentation regarding architectural constraints, OS security boundaries, and external dependencies for Fahad's Studio.

---

## 1. Code Signing & Distribution

### Windows SmartScreen
- **Current State:** The Windows build generated by `pnpm --filter @irfan/desktop dist:win` produces an **unsigned** NSIS installer executable.
- **Consequence:** Windows SmartScreen will display an "Unknown Publisher" warning on first launch.
- **Resolution:** Requires an EV (Extended Validation) or OV code-signing certificate from a trusted Certificate Authority configured in `electron-builder`.

### Android APK Debug Keystore
- **Current State:** The Android APK generated in CI is signed using the temporary Android Debug keystore.
- **Consequence:** Upgrading between builds may result in signature mismatch errors requiring an uninstall/reinstall cycle, which clears the local Android Keystore device token.
- **Resolution:** A permanent client-supplied production release keystore (`.jks` / `.keystore`) must be configured in `apps/android/app/build.gradle.kts`.

## 2. Voice & Wake-Word Limitations

### Desktop Wake-Word Recognition
- **Mechanism:** Desktop "Hey Jarvis" detection currently uses the Chromium Web Speech API (`SpeechRecognition`).
- **Limitations:**
  - Operates only while the Electron window is active and rendering.
  - Requires network access to Google's speech recognition services for speech-to-text tokenization.
  - Not an embedded, low-power Keyword Spotting (KWS) model like Snowboy or Porcupine.
  - Highly noisy environments or accented speech may yield occasional false rejects.
- **Fallback:** Push-to-Talk (PTT) via the primary microphone button is fully robust, local-first in capture, and remains the primary recommended input method.

### Android Wake Word (Picovoice Porcupine)
- **Mechanism:** Android implements a native foreground service (`WakeWordService.kt`) utilizing the Picovoice Porcupine C library.
- **Limitations:**
  - Requires a valid Picovoice `AccessKey`. Picovoice imposes strict licensing terms (Free tier limited to 3 unique devices per account).
  - Without an active key entered into the Android settings, the wake word service will safely refuse to start.
  - OEM battery optimizers (Samsung OneUI, Xiaomi MIUI) may throttle background foreground services unless battery optimization is manually disabled by the user.

## 3. Messaging & WhatsApp Integration

### Unofficial WhatsApp Web Library (`whatsapp-web.js`)
- **Mechanism:** Uses a headless Chromium instance to authenticate with WhatsApp Web via local QR scanning.
- **Limitations & Risks:**
  - `whatsapp-web.js` is an **unofficial, reverse-engineered integration**. WhatsApp frequently modifies internal web protocol classes, which can temporarily disrupt chat synchronization until the library updates.
  - Risk of account suspension if used for unsolicited messages or bulk broadcasting. The system includes an intentional daily outbound quota (`IRFAN_WA_DAILY_SEND_LIMIT`, default 30) and strictly enforces manual human approval on every single message.
  - Dedicated Number Requirement: The user should pair a dedicated assistant secondary number rather than their personal WhatsApp account.

### LocalAuth Profile Encryption
- **Limitation:** The Chromium browser session generated by `LocalAuth` contains session cookies and local storage tokens.
- **Mitigation:** The application stores these under the user's OS profile with `0700` directory permissions. Full encryption at rest requires OS-level BitLocker or Windows EFS. Session files must never be shared across machines.

## 4. Google Gmail OAuth & Scope Verification

### Google Restricted Scopes
- **Scopes Requested:** `https://www.googleapis.com/auth/gmail.modify`
- **Limitations:**
  - Google Cloud treats `gmail.modify` as a **Restricted Scope**.
  - While in "Testing" mode in the Google Cloud Console, only authorized test email accounts (up to 100 users) can log in.
  - Publishing for public multi-tenant access requires passing a third-party CASA Tier 2/3 security assessment.
  - For single-client private deployment, the owner must create a Google Cloud Project, enable the Gmail API, configure OAuth Consent, and whitelist their own email address.

## 5. Media & Video Studio

### Cloudflare Worker Compute Boundaries
- **Architectural Boundary:** Cloudflare Workers run on V8 isolates and **cannot** execute arbitrary C/C++ native binaries, native Node addons, or FFmpeg subprocesses.
- **Design:** All heavy video editing operations are intentionally hosted locally on the Windows desktop machine (`apps/desktop/src/video-engine.ts`) where local CPU/GPU acceleration is available. The Cloudflare Worker functions strictly as an API gateway, AI Director prompt generator, and fal.ai queue dispatcher.

### fal.ai Cost Management
- **Budget Gating:** Paid video generation (`wan/v2.6`) incurs real third-party billing costs per generated second.
- **Default Safeguard:** The application enforces a default \$0 to \$5 daily spending cap via `FAL_DAILY_LIMIT_USD`. If `FAL_KEY` is not present, all cloud generation routes return descriptive configuration alerts while keeping all free local FFmpeg editing workflows completely functional.

## 6. Android Platform Security Restrictions

### System Radio & Settings Toggles
- **Android Restriction:** Modern Android versions (Android 10+) strictly prohibit third-party apps from programmatically toggling Wi-Fi, Bluetooth, or Airplane Mode silently.
- **Behavior:** The JARVIS Android companion gracefully redirects the user to the native system settings panel (`Settings.Panel.ACTION_WIFI`) where the user retains final physical control over system toggles.

### Background Audio Capture
- **Android Restriction:** Android restricts continuous background microphone recording when an app is not running an active foreground service with an explicit ongoing notification.
- **Behavior:** When wake listening is enabled on Android, a persistent status bar notification is displayed ("JARVIS wake word enabled — Microphone active") to comply with Android privacy requirements.
